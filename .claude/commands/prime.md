# Prime Context

Load full project context before starting work.

## Steps:

1. **Review Recent Changes**: Check git log for last 5 commits
2. **Check Current Status**: Run git status to see uncommitted changes
3. **Load Config**: Read src/utils/config.py for current settings
4. **Check Cache State**: List cache/ directory contents with timestamps
5. **Review Output**: Check output/ for recent reports
6. **Verify Dependencies**: Confirm yt-dlp version is current

## Summary Output:
- Current branch and recent commits
- Any uncommitted changes
- Active accounts in config
- Current date filters
- Cache freshness (last scrape times)
- Available reports

This ensures full context before making any changes.
