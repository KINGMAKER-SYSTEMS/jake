# Show Campaign Statistics

Display statistics for scraped campaigns and accounts.

## Target: $ARGUMENTS

1. Read cached data from cache/ directory
2. Aggregate statistics:
   - Total accounts scraped
   - Total videos collected
   - Total views across all videos
   - Date range of content
   - Top performing songs by views
   - Top performing accounts by engagement
3. If a specific campaign or account is specified in arguments, filter to that
4. Display results in a clean, readable format
